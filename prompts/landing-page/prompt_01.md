Acesse o Canva e crie uma nova landing page/site de uma única página para um produto digital experimental de controle financeiro para pequenos empreendedores e autônomos.

IMPORTANTE:
- Esta é uma landing page de Product Discovery, não uma página de um produto já lançado.
- Crie primeiro toda a estrutura visual e o design da página.
- Não configure ainda formulários, links, CTA funcionais ou publicação.
- Não invente depoimentos, clientes, estatísticas, números de mercado ou resultados comprovados.
- Não use estética de banco tradicional nem visual excessivamente tecnológico.
- O resultado deve transmitir confiança, organização, simplicidade e profissionalismo.

## DIREÇÃO VISUAL

Estilo geral:
- Clean, moderno, profissional e sofisticado.
- Vibe de fintech moderna, mas acessível para pequenos empreendedores.
- Usar como referência visual: Clean Minimal + Swiss Modernist.
- Muito espaço em branco.
- Layout organizado em blocos bem definidos.
- Hierarquia visual clara.
- Evitar excesso de elementos decorativos.
- Evitar gradientes exagerados, sombras fortes, 3D e elementos futuristas.
- Priorizar formas geométricas simples, cards, linhas finas e ícones minimalistas.

Paleta:
- Fundo principal: branco ou off-white muito claro.
- Cor principal: azul-marinho profundo, transmitindo confiança e estabilidade.
- Cor secundária: azul médio.
- Cor de destaque: verde financeiro discreto, utilizado apenas para resultados positivos, indicadores e pequenos detalhes.
- Texto principal: azul-marinho/cinza muito escuro.
- Texto secundário: cinza médio.
- Usar a cor verde com moderação; ela não deve dominar a página.

Tipografia:
- Usar uma fonte sans-serif moderna e altamente legível.
- Títulos: peso semibold/bold, grandes e com bastante espaçamento.
- Textos: regular/medium, tamanho confortável.
- Evitar fontes decorativas.
- Manter no máximo duas famílias tipográficas.

Elementos visuais:
- Ícones lineares, simples e consistentes.
- Bordas levemente arredondadas.
- Cards com bordas sutis e sombras muito suaves.
- Gráficos simples e minimalistas.
- Não utilizar fotografias genéricas de pessoas sorrindo como elemento principal.
- A interface financeira deve ser o principal elemento visual.

## ESTRUTURA DA PÁGINA

### 1. HERO

Criar uma seção inicial ampla, limpa e com bastante espaço negativo.

Layout:
- Texto principal à esquerda.
- Representação visual de um pequeno dashboard financeiro à direita.
- No topo, reservar espaço para uma marca/nome do produto à esquerda e navegação simples à direita.

Hierarquia:
- Pequeno texto de apoio acima do título.
- Headline grande e forte.
- Subheadline menor.
- Espaço reservado para CTA principal.

Headline:
"Saiba quanto seu negócio realmente está dando de lucro."

Subheadline:
"Registre suas receitas e despesas de forma simples e tenha uma visão clara de quanto entrou, quanto saiu e quanto realmente sobrou."

Texto complementar:
"Sem planilhas complicadas. Sem precisar entender contabilidade."

O CTA deve ter aparência de botão principal, mas ainda não precisa ser funcional.

O dashboard do lado direito deve parecer uma interface financeira real, porém simples e fictícia.

### 2. SEÇÃO PROBLEMA

Criar uma seção com fundo levemente contrastante em relação ao Hero.

Título:
"Você sabe quanto seu negócio realmente deixou de lucro este mês?"

Criar três cards horizontais:

1. "Quanto realmente sobrou?"
2. "Onde o dinheiro está indo?"
3. "Seus preços estão certos?"

Cada card deve possuir:
- ícone linear;
- título curto;
- pequeno texto explicativo;
- bastante espaço interno.

Os cards devem parecer problemas reais, não funcionalidades do produto.

### 3. PROPOSTA DE VALOR

Criar uma seção branca, bastante limpa.

Título:
"Um jeito mais simples de entender o dinheiro do seu negócio."

Abaixo, criar três etapas visualmente conectadas:

01 — "Registre"
"Anote receitas e despesas sem complicação."

02 — "Entenda"
"Veja para onde o dinheiro está indo e quanto realmente sobrou."

03 — "Decida"
"Use essas informações para tomar decisões melhores."

Usar números grandes e discretos, ícones lineares e uma linha visual conectando as três etapas.

### 4. COMO FUNCIONA

Criar uma seção visual mostrando uma transformação.

Título:
"Do registro à clareza."

Criar três blocos em sequência:

ENTRADA
Exemplos de movimentações:
"Recebi R$ 450 de um serviço"
"Gastei R$ 120 com material"

↓

ORGANIZAÇÃO
Mostrar visualmente essas informações sendo organizadas por categoria.

↓

VISÃO
Mostrar um pequeno resumo financeiro com:
Receitas
Despesas
Resultado

O objetivo desta seção é fazer o visitante entender o conceito rapidamente.

### 5. MOCKUP PRINCIPAL DA SOLUÇÃO

Criar uma seção de destaque visual.

Título:
"Tenha uma visão clara do seu negócio."

Criar um mockup grande de dashboard financeiro.

O mockup deve conter visualmente:

Receitas: R$ 4.850
Despesas: R$ 2.420
Resultado: R$ 2.430

Também mostrar categorias de despesas, por exemplo:
- Materiais
- Transporte
- Serviços
- Outros

Adicionar um pequeno bloco de "Ponto de atenção".

IMPORTANTE:
Adicionar de forma discreta a indicação:

"Exemplo ilustrativo — dados fictícios."

O dashboard deve parecer uma interface de produto SaaS/fintech moderna, mas sem excesso de elementos.

### 6. PARA QUEM É

Criar uma seção com fundo levemente diferente.

Título:
"Feito para quem trabalha por conta própria."

Criar três cards:

"Prestadores de serviço"
"Profissionais autônomos"
"Pequenos negócios"

Cada card deve possuir um ícone simples e uma descrição curta.

Não apresentar o produto como solução exclusiva para MEIs.

### 7. CTA FINAL

Criar uma seção visualmente forte, mas minimalista.

Título:
"Quer experimentar essa ideia antes de ela ser lançada?"

Texto:
"Estamos testando uma forma mais simples de ajudar pequenos empreendedores a entender melhor suas finanças."

Criar um botão grande:

"Quero participar do teste gratuito"

O botão deve utilizar a cor principal da identidade visual.

Ainda não configurar o link.

### 8. RODAPÉ

Criar um rodapé simples.

Reservar espaço para:
- nome/marca;
- pequena descrição;
- informação de que a solução está em fase de validação.

Não adicionar links ou informações inventadas.

## REGRAS DE DESIGN

- Manter alinhamento consistente entre todas as seções.
- Usar uma largura máxima de conteúdo confortável para desktop.
- Criar espaçamento vertical generoso entre seções.
- Garantir contraste adequado entre texto e fundo.
- Manter o mesmo padrão de bordas, ícones e cards em toda a página.
- O dashboard/mockup deve ser o principal elemento visual depois do Hero.
- A página deve parecer uma startup fintech profissional, mas não uma instituição financeira tradicional.
- Priorizar clareza sobre quantidade de elementos.
- Não deixar a página visualmente carregada.
- Garantir que a hierarquia visual conduza naturalmente:
  Problema → Solução → Funcionamento → Visualização → CTA.

Antes de finalizar, revise a página inteira e garanta que todas as seções estejam visualmente coerentes entre si.

Não publique ainda e não configure funcionalidades. Apenas crie a estrutura visual completa.
